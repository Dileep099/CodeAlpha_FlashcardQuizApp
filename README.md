# Flashcard Quiz App (Android)

A simple flashcard app for studying. Each card shows a question on the front and the answer on the back.

## Features
- Show Answer / Hide Answer button
- Next and Previous navigation
- Add, Edit and Delete flashcards
- Clean UI with gradient background and card layout

## Tech Stack
- Java
- XML layouts (Material Components)
- Android Studio
